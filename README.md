ISWREQUERIMIENTOS202502-1Santix19

Este proyecto fue desarrollado como parte del curso de Ingeniería de Requisitos del segundo semestre del programa de Ingeniería de Software.  
Su propósito es diseñar y documentar los requerimientos de un Sistema de Gestión de Talleres y Seminarios.
El sistema busca facilitar procesos como el registro de eventos, la inscripción de participantes, la gestión de materiales, el control de asistencia y la generación automática de certificados digitales.
